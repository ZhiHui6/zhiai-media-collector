# PRD：智爱媒体素材采集器

## 背景

微信公众号不提供图片批量保存能力，手动逐张保存繁琐且常拿到压缩图、错误扩展名。本软件面向需要归档社媒素材的用户，提供「粘贴链接 → 解析 → 一键批量下载」的完整桌面体验。

产品名与标识不含平台词，为后续接入微信视频号、小红书、抖音等平台预留空间；这些平台目前尚未实现，界面文案不得提前宣称支持。

## 目标用户与平台

- Windows x64 桌面用户（Win10 1803+）
- Rust 核心 + Tauri 2 壳 + Vue 3 前端；以 NSIS/MSI 安装包分发，运行时依赖系统 WebView2（Win10 1803+ 随系统提供）

## 核心功能

| 编号 | 功能 | 优先级 |
|---|---|---|
| F1 | 粘贴单/多个公众号链接，自动识别链接种类 | P0 |
| F2 | 普通图文文章图片提取（正文配图、封面、头像、二维码） | P0 |
| F3 | 图片消息（相册轮播）整组图片提取 | P0 |
| F4 | 图片类型标注与筛选 | P0 |
| F5 | 原图地址还原（/640→/0、去转码参数）与去重 | P0 |
| F6 | 一键批量下载，完整队列管理（并发/进度/速度/重试/暂停/取消） | P0 |
| F7 | 真实格式嗅探（字节级，不信任 wx_fmt），扩展名纠正 | P0 |
| F8 | 格式转换 JPG/PNG/WebP（GIF 动图保留原始字节） | P0 |
| F9 | 下载历史持久化与查看 | P1 |
| F10 | 设置持久化（目录/并发/重试/转换参数） | P1 |
| F11 | 合集/专辑页枚举文章链接（尽力而为） | P2 |
| F12 | 外观主题：跟随系统 / 亮色 / 暗色，即时切换并持久化 | P1 |

## 非功能需求

- 并发默认 4（1–16 可调），单图上限 64MB，进度事件节流 100ms
- 数百图网格不卡顿（前端行虚拟化 + 壳层 PNG 有界 LRU + `media://` 自定义协议，图片不走 JSON IPC）
- 微信验证页/接口受限给出明确中文提示，不静默失败
- 原子写盘与配置损坏回退，取消/重试不留半成品
- 交互约定：卡片单击选中、双击大图、右键风格化菜单；Enter 解析、Ctrl+A 全选、Esc 关闭浮层；禁用原生右键菜单与原生 title，一律应用内 tooltip；开关行只有开关可点；说明小字单行且滑杆标注范围；被省略文字悬停可见全文

## 边界与约束

- 不登录微信、不抓取历史消息列表、不破解验证
- 合集接口受限时引导用户手动复制文章链接
- 仅下载用户主动提供的链接内容，供个人归档使用
